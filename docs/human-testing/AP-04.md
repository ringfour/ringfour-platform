# AP-04 — use the independent local Python wheels

Accepted on 23 November 2026 for `uv` and local wheels. No Platform/virtual
restart is needed. Public Python publication is deferred; the portable bundle
is the distribution artifact. See [evidence](../evidence/AP-04.md) and the
[packaging contract](../python-distribution.md).

## 1. Locate and verify the prepared bundle

```sh
cd /home/cdr/.local/share/ringfour/python-artifacts/0.1.0.dev0
sha256sum --check SHA256SUMS
```

Every file should report `OK`. The manifest pins package commits, versions,
wheel hashes and image/dependency digests. Preserve it with the complete bundle
when transferring to another host. The bundle includes `linux-amd64` and
`linux-arm64`; execution was verified on amd64. Select the directory matching
the consumer interpreter/engine architecture, rather than the host shell when
using a remote engine. Locks require CPython 3.13 on glibc Linux.

## 2. Install SDK alone with uv

From the bundle root, using a new environment outside the bundle:

```sh
uv venv --python 3.13 /tmp/ringfour-ap04-sdk
uv pip install --python /tmp/ringfour-ap04-sdk/bin/python --offline --no-index \
  --find-links linux-amd64/wheels --require-hashes --only-binary=:all: \
  -r linux-amd64/requirements-sdk.txt
/tmp/ringfour-ap04-sdk/bin/python -c 'from ringfour import Robot; print(Robot.imu)'
```

The final command prints the SDK method without connecting to a robot or
Platform. Installation uses only bundle files. No ROS, Runner, editable source
install or optional Platform runtime is needed. `uv` may provision Python when
creating the environment; the subsequent package installation is offline.

## 3. Install runtime alone or combine the packages

```sh
uv venv --python 3.13 /tmp/ringfour-ap04-runtime
uv pip install --python /tmp/ringfour-ap04-runtime/bin/python --offline --no-index \
  --find-links linux-amd64/wheels --require-hashes --only-binary=:all: \
  -r linux-amd64/requirements-runtime.txt
/tmp/ringfour-ap04-runtime/bin/python -c \
  'from ringfour_runtime import artifacts, interactions, logbook; import importlib.util; assert importlib.util.find_spec("ringfour") is None'
```

Use `requirements.txt` to install both packages in a fresh environment.
Runtime calls need Daemon URLs and execution-scoped credentials supplied by
infrastructure. Calling them outside a configured execution fails explicitly.
Do not invent a token to exercise live writes: App credential/delivery support
belongs to AP-10. Existing client examples are in the
[runtime README](../../packages/python-runtime/README.md).

## 4. Build an independent consumer image

From the bundle root:

```sh
docker build --network none -t ringfour-sdk:ap04 .
docker run --rm --network none ringfour-sdk:ap04
docker build --network none --build-arg INSTALL_RUNTIME=true -t ringfour-sdk-runtime:ap04 .
docker run --rm --network none ringfour-sdk-runtime:ap04 python -c \
  'from ringfour import Robot; from ringfour_runtime import artifacts, interactions, logbook; print(Robot.imu)'
```

These standalone images are not Ringfour stack services. Building may pull the
pinned base images; dependency installation runs offline. No sibling repository
or Runner vendor path is in the context. No engine socket is mounted in the
consumer. The image runs a plain Python command; it is not a published App.

## 5. Repeat the integrity and recovery checks

```sh
cd /home/cdr/ringfour/ringfour-platform
python3 tests/e2e/ap04-packages.py \
  --bundle /home/cdr/.local/share/ringfour/python-artifacts/0.1.0.dev0
```

Expected result: `passed: true`, including offline install, optional runtime,
runtime without SDK, a tampered wheel refused by its hash, reproducible bundle
checksums and refusal to overwrite an existing output. The harness tampers only
with a temporary copy, creates isolated containers/images, and removes those
images afterward. It does not stop/reload Platform or virtual.

To rebuild rather than consume, use `uv` 0.13.8, Python >=3.12 for the script,
network access for pinned build/dependency downloads and repositories containing
the exact source commits in `release.json`:

```sh
python3 scripts/build-python-artifacts.py --output /tmp/ringfour-python-rebuild
```

The destination must not exist. Build Python 3.13.18 is selected explicitly;
each wheel must match its recorded checksum. Do not overwrite the accepted
bundle or update its checksum to hide a different build. Changed package
contents require a new package version and bundle recipe.
