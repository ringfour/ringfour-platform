## 3. Confirm owner authorization

In the same CLI environment, run this owner-only read with the existing login.
Replace the organization UUID and API URL if the deployment uses another port.
It reads the CLI token without printing it.

```bash
export AP02_ORG_ID='<original organization UUID>'
export RINGFOUR_API_URL=http://localhost:8080
uv run --project apps/cli python - <<'CHECK'
import os
import uuid
import httpx
from ringfour_cli.auth import TokenStore
from ringfour_cli.config import load_settings

settings = load_settings()
tokens = TokenStore().load(settings)
assert tokens, 'Run ringfour-cli login first'
org = str(uuid.UUID(os.environ['AP02_ORG_ID']))
url = f'{settings.api_url.rstrip("/")}/v1/organizations/{org}/invitations'
response = httpx.get(url, headers={'Authorization': f'Bearer {tokens["access_token"]}'}, timeout=30)
print('Owner-only request:', response.status_code)
print('Unauthenticated request:', httpx.get(url, timeout=30).status_code)
CHECK
```

Pass: owner-only request returns 200; unauthenticated request returns 401.
Invitations are empty because they were excluded from the reset. If a retained
