## Implemented boundary

- The executor supplies independently derived run credentials, runtime origins
  and one owner-labeled per-run artifact volume. The private key is persisted
  beside SQLite; only hashes/expiry/revocation enter its credential rows. Runner
  secrets, enrollment credentials, human/registry tokens, sockets and daemon-data
  are never supplied to Apps. Terminal credentials are rejected; replacement
  retains the same App credential/container. Fresh engine reads distinguish
  running, terminal and unknown state before runtime effects.
- Existing packaged Logbook, HITL and artifact clients work unchanged. Human
  submission remains provisional until a durable device application; timeout,
  cancellation, competing answers and wrong-run access retain distinct outcomes.
  Unknown engine state never invents cancellation/approval. A delayed development
  restart cannot bypass an App's local execution slot; mission workers also
  consult the shared hosted slot before legacy launch.
- Artifact publication checks relative paths and symlink traversal, exact owned
  container, one regular file, 16 MiB/file and 16 retained publications/run. It
  fsyncs a private byte snapshot and metadata before local acknowledgement.
  Changed/deleted sources cannot alter a replayed publication. Hosted SHA-256/
  identity checks precede confirmation; local byte cleanup follows confirmation.
  Metadata and engine artifact volumes remain under documented retention.
- Output preserves bounded 64 KiB prefixes, independent stream offsets, seals and
  truncation. Metadata-only truncation changes are delivered even with an unchanged
  prefix length. Exact byte retries are accepted after run completion; changed
  content, gaps and appending beyond a seal are refused. Lost containers seal
  retained prefixes with explicit truncation. Per-run output/bytes/history remain
  authorized by consumer workspace, never publisher listing.
- EF AppRuntimeEvidence adds App output/artifact storage and nullable App operation/
  installation links on retained Logbook events. SQLite 0020 adds artifact spool
  metadata and durable output delivery acknowledgements. Lifecycle events and
  v3 App history preserve run/revision/config/actor attribution and identical
  event IDs under workspace/App/installation/run filters. Legacy history/readers
  and runtime paths remain available to legacy clients.
