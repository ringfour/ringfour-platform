# AP-12 CLI implementation evidence

## Implemented

- Added `app search`, `show`, `import`, `imports`, `install`, `installations`,
  `configure`, `update`, `start`, `stop`, `operation`, `run`, `logs`,
  `artifacts`, `artifact`, `interaction`, `respond`, and `logbook` commands.
- Added `robot capabilities` with optional server compatibility assessment.
- Added `app rollback` to restore a previous release and configuration revision
  while idle, without creating a run.
- Installation targets resolve only within the selected organization. Starting
  by App ID requires an explicit robot and refuses ambiguous installations;
  stop requires the exact run ID.
- Mutations send idempotency keys. Configuration is submitted as JSON and is
  validated by the Platform. Artifact downloads verify declared size and
  SHA-256. Output reading pages through the bounded durable streams.
- Updated [CLI documentation](../../apps/cli/README.md) and the
  [operator acceptance guide](../human-testing/AP-12.md).
