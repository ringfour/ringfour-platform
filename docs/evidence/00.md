## Notes and decisions

- .NET runs only in Docker (pinned `sdk:10.0`/`aspnet:10.0`); `scripts/dotnet.sh` is the wrapper.
  Build artifacts and NuGet/tool caches live in named volumes because container-written files on
  the macOS bind mount caused bogus mtimes (MSBuild DateTimeOffset overflow) and stale handles.
- The component-test SDK container mounts the host Docker socket so Testcontainers can spawn
  PostgreSQL (dev tooling only; runtime services never mount it; runner is isolated).
- postgres:18 images store data in `/var/lib/postgresql` (not `.../data`) — compose volume mounts there.
- API fails fast if PostgreSQL is unavailable at startup (compose gates it on pg healthcheck);
  readiness reports dependency state afterwards.
- Console uses the Ringfour interface system tokens from `ringfour/design/design_system`
  (vendored Space Grotesk fonts + OFL in `apps/console/public/fonts`, Inter via @fontsource);
  no cross-import of the design project.
- Auth0 gates belong to milestone 01; nothing in 00 required external credentials.
