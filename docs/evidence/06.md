## Setup and versions

2026-11-12, macOS arm64, .NET SDK 10.0.403, EF CLI 10.0.0, Node 26.13.0,
uv 0.12.1, Python 3.13, Docker Engine 28.3.3 and PostgreSQL 18. The Python
apps' resolved dependencies are in their respective `uv.lock` files.
The main acceptance uses the user's existing Auth0 device login and an isolated
organization, robot, database, filesystem object store, daemon and Runner.
`tests/e2e/06-missions.sh` builds local `:06-test` images; allocates its own
network, containers and volumes; binds test API/daemon ports to loopback; and
removes those resources on exit. It requires Docker, `uv`, `.auth.env`, and an
existing CLI login. It does not modify a real robot. Dependency downloads
require network access. The user's `analysis.md` remains untouched.

```bash
npm --prefix packages/contracts test
(cd apps/cli && uv run ruff check src tests && uv run pytest -q)
(cd apps/daemon && uv run ruff check src tests && uv run pytest -q)
(cd apps/runner && uv run ruff check src tests && uv run pytest -q)
DOTNET_CLI_TELEMETRY_OPTOUT=1 /tmp/ringfour-dotnet-sdk-10/dotnet format apps/api --no-restore
DOTNET_CLI_TELEMETRY_OPTOUT=1 /tmp/ringfour-dotnet-sdk-10/dotnet test apps/api --no-restore
bash tests/e2e/06-upgrade.sh
bash tests/e2e/06-missions.sh
bash tests/e2e/05-scripts.sh
```

The upgrade script needs the local .NET SDK and restored `dotnet-ef` tool
(`cd apps/api && dotnet tool restore`); override `DOTNET_ROOT` if the SDK is
elsewhere. It creates and removes a separate PostgreSQL container, migrates to
05, inserts a finalized 05 script revision, migrates to the latest version,
and verifies that revision survives and the new attribution columns exist.
The isolated 06 API starts from an empty database and applies all migrations.

`docs/human-testing/06.md` and `docs/missions-contract.md`. Start and restart
reserve an execution ID before the worker creates the execution, so execution
lookup can briefly return 404; action/deployment status is authoritative during
that interval. There is no automatic restart policy. A mission Python
environment is not a security sandbox.
