New design: [run contract](../apps-runs.md). Existing AP-01 start/stop/run schemas
are implemented. Negotiation adds an optional supports_app_runs boolean, default
false, so installation-only Daemons cannot receive run dispatch. All consumers
and fixture defaults were updated. execution_failed is now a defined App failure.
EF migration AppRunDispatch adds that capability and limits the pending mutation
index to installation changes; Start and exact-run Stop can coexist. SQLite 0019
retains operation reports and run fingerprints and supports prelaunch stop.

The API locks the robot and shares AP-02 execution exclusion with legacy and dev
paths. It commits immutable snapshot/intent/idempotency together. Acknowledgement
never sets running. The Daemon checks installed generation and fresh Agent/engine
compatibility before create, never pulls on start, and persists ordered reports.
Stop binds installation and expected run, including cancellation before create.
Fast exits and nanosecond engine timestamps are normalized for the public wire.
Unknown engine state retains the slot; ambiguous start never relaunches.
