  using recorded backend constraints and epoch; expected SHA-256 checks passed.

  the entire bundle. A repeated build to an existing output path was refused.
- All downloaded amd64/arm64 dependency wheels matched their pins. Consumer
  execution was linux/amd64 only; arm64 execution is not claimed.
