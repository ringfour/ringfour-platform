# Legacy Runner

This package implements the compatibility Runner retained during the Apps
migration. It is not the deployment path for new Apps. Its former setup,
runtime and wheelhouse documentation is preserved in the
[mission-era archive](../../docs/archive/legacy-mission-workflows/applications/runner-README.md).

The active execution architecture is described in
[`docs/architecture.md`](../../docs/architecture.md), with App lifecycle and
runtime details in [`docs/apps-runs.md`](../../docs/apps-runs.md) and
[`docs/apps-runtime.md`](../../docs/apps-runtime.md). AP-15 owns final Runner
retirement after its remaining callers are migrated and accepted.
